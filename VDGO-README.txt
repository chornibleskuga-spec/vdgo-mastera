===========================================
VDGO Master - Запуск на рабочем ПК
===========================================

1. УСТАНОВИТЕ Node.js:
   - Откройте https://nodejs.org
   - Скачайте "LTS" версию (рекомендуется 20.x)
   - Установите (Next -> Next -> Finish)

2. РАСПАКУЙТЕ архив:
   - Распакуйте папку "vdgo-master" в любое место
   - Например: C:\Users\ВашеИмя\Desktop\vdgo-master

3. ЗАПУСК (два способа):

   СПОСОБ А - Через start.bat:
   - Дважды кликните на "start.bat"
   - Дождитесь надписи "Server running"
   - Сайт откроется автоматически в браузере

   СПОСОБ Б - Вручную:
   - Откройте командную строку (cmd)
   - Перейдите в папку: cd C:\Users\...\vdgo-master
   - Выполните: npm install
   - Выполните: npm run build
   - Выполните: npm start
   - Откройте в браузере: http://localhost:3000

4. ДЛЯ КОЛЛЕГИ в одной сети:
   - Узнайте IP вашего ПК: ipconfig | findstr IPv4
   - Коллега открывает: http://ВАШ_IP:3000

5. ДЛЯ ТЕЛЕФОНА:
   - Откройте на телефоне: http://IP_ВАШЕГО_ПК:3000
   - Должны быть в одной WiFi сети
